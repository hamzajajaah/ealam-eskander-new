01 - دورة HTML

تعلم بناء صفحات المواقع من البداية.

الدرس الأول: إنشاء أول صفحة

HTML هي لغة بناء هيكل صفحات الويب.

<!DOCTYPE html>
<html lang="ar">
<head>
<meta charset="UTF-8">
<title>موقعي الأول</title>
</head>
<body>
<h1>مرحباً بالعالم</h1>
<p>هذه أول صفحة لي</p>
</body>
</html>
الدرس الثاني: العناوين والفقرات 
<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<p>هذه فقرة تعليمية</p>
الدرس الثالث: الروابط والصور 
<a href="https://example.com">افتح الموقع</a>
<img src="photo.jpg" alt="صورة">
